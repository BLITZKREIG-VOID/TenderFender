# Retrieval Tuning Procedure (Phase 4)

This document specifies the Phase 4 procedure for evaluating and tuning retrieval cutoff scores for guideline citations (SoT §8.4 RAG rules, D12).

## Procedure

1. **Remove Placeholders**
   - Replace fixture/placeholder passages with authoritative procurement guidelines in `kb/passages/` (provided by P1).
   - Ensure no passage in `kb/passages/` contains `PLACEHOLDER` in its `source_title`.
   - The `--allow-placeholder` flag is strictly for testing and mock runs; production tuning runs without it.

2. **Run Retrieval Inspection**
   Execute `scripts/inspect_retrieval.py` on the pipeline fusion intermediate outputs against the knowledge base:

   ```bash
   # Embedding retriever (default)
   SENTENCE_TRANSFORMERS_HOME=.cache/models HF_HUB_OFFLINE=1 \
     python scripts/inspect_retrieval.py \
       --fusion-dir artifacts/fusion \
       --kb-dir kb/passages \
       --retriever embedding \
       --top 6 \
       --format markdown

   # Keyword retriever (token-overlap fallback)
   python scripts/inspect_retrieval.py \
     --fusion-dir artifacts/fusion \
     --kb-dir kb/passages \
     --retriever keyword \
     --top 6 \
     --format markdown
   ```

   *Note on missing KB:* If `--kb-dir` does not exist or contains no `KB-*.md` files, the tool prints `no passages found in <path>` to `stderr` and exits with non-zero exit code `1`.

3. **Mark Relevance by Hand**
   - Copy the Markdown table generated by the tool into the [Results Table](#results-table) section below.
   - For each candidate passage, manually verify whether its text directly supports or regulates the specific finding or collusive ring indicator.
   - Fill the empty `Relevant?` column with `yes` or `no`.

4. **Select Cutoff Threshold**
   - Analyze the distribution of scores for relevant vs. irrelevant passages.
   - Choose a cutoff threshold such that relevant passages meet or exceed the cutoff (`score >= cutoff`) and irrelevant passages fall below it (`score < cutoff`).
   - Current defaults (defined in `decision.retrieve.DEFAULT_MIN_SCORE`):
     - `embedding`: `0.30`
     - `keyword`: `0.04`

5. **Tuning Principles**
   - **Prefer fewer citations over wrong ones:** An uncited finding with an explicit note ("no guideline passage retrieved") is compliant and sound; citing an irrelevant guideline is a hallucination defect.
   - **Never lower cutoff to force a citation:** If no retrieved passage genuinely addresses the finding or ring indicator, let it drop below the cutoff.

6. **Log Cutoff Decisions**
   - Record the chosen cutoffs, date, rationale, and score boundaries in `SOURCE_OF_TRUTH.md` Section 13 (Decisions log table, Lead append-only).
